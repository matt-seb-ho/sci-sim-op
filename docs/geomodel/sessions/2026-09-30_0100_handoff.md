- Data root: `/data/matt/sci-sim-op/geomodel/forge/`, with files in `raw/<gdr_id>/`.
  `manifest.json` is a dict with the record list inside. Non-GDR records lack
  `date_published`, so guard for it.
- **Never mount the manifest, `meta/`, or GDR page caches into the sandbox.** They carry
  `role_guess=model` labels and titles that name the answer.
- **The expert answer, GDR 1205:**
  - `raw/1205/Mesh Files.zip` → `2019.08.21_global_cell.csv` has `#` comment header
    lines. The label column is `GM_8_19_2019`, with values `Granitiod` (sic) and
    `Basin Fill`.
  - **The misspelling "Granitiod" and the string "GM_8_19_2019" are canaries for the
    leak scan.**

    zips. The stress columns are Excel **formulas**, so check whether cached values
    exist (openpyxl `data_only=True`) or recompute them from the formulas.

    per-cell K and porosity.
